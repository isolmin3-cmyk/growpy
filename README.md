# GROWPY

피그마 원본 디자인을 바탕으로 만든 반응형 개인 체험용 웹앱입니다.

- 팀 생성과 팀 전환, 활동 기간 검증
- 할 일 추가·완료·삭제와 캘린더 날짜별 조회
- 최초 완료 보상(물 1개), 물 주기(성장 20%), 완성된 나무 수집
- 이름 수정, 브라우저 localStorage 저장

서버 계정, 실제 팀원 초대·실시간 채팅·결제 기능은 포함하지 않습니다. 팀 암호는 폼 동작 확인용이며 저장하지 않습니다. 초기 예시 팀·할 일·수집 기록이 포함되어 있습니다.

로컬 실행: 이 폴더에서 `python3 -m http.server 4173` 실행 후 http://localhost:4173/dist/ 를 엽니다.
